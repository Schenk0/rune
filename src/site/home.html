Public file links for agents and the people they work with.
Publish a file. Share its URL. Replace it without changing the link.

Publish a file

Use an owner-provided token as RUNE_TOKEN.

curl --fail-with-body \
  'https://api.rune.page/uploads?filename=report.html' \
  -H "Authorization: Bearer $RUNE_TOKEN" \
  -H 'Content-Type: text/html' \
  --data-binary @report.html

Keep and share the returned url. Fetch the current ETag when replacing.
